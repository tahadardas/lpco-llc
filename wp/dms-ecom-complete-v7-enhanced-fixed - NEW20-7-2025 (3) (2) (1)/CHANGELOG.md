# Changelog - LPCO LLC Commerce Plugin

جميع التغييرات الموثقة لإضافة متجر وتطبيق LPCO.

## [7.1.0] - 2026-11-24

### ✨ ميزات جديدة (Added)
- **إدارة مباشرة لكلمات المرور (Direct Customer Password Management)**:
  - إمكانية تعيين وتوليد كلمات مرور جديدة للزبائن والتجار مباشرة من لوحة الإدارة (`dms_members` وصفحة `users.php`) دون الحاجة لروابط إعادة التعيين أو البريد الإلكتروني.
  - نافذة منبثقة (Modal Dialog) متوافقة بالكامل مع هوية ووردبريس وتصميم الإضافة، وتدعم الواجهة العربية (RTL).
  - زر توليد كلمة مرور عشوائية قوية على الخادم بطول 16 حرفاً باستخدام `wp_generate_password`.
  - زر إظهار وإخفاء كلمة المرور (Show/Hide Toggle).
  - زر نسخ كلمة المرور المستقلة (Copy Password).
  - زر نسخ بيانات الدخول الكاملة للزبون وفق القالب المعتمد للشركة للإرسال المباشر عبر واتساب.
  - نقطة نهاية REST API إدارية جديدة: `POST /dms/v1/admin/members/{id}/password`.

### 🔒 أمان وصلاحيات (Security & Permissions)
- التحقق الصارم من صلاحيات المنفذ باستخدام `current_user_can('edit_user')` و `manage_options`/`edit_users`.
- منع استهداف وتعديل حسابات المديرين والمشرفين وموظفي النظام من شاشة الزبائن لحماية أمن الموقع.
- الحماية من هجمات CSRF باستخدام WordPress Nonce (`check_ajax_referer`).
- منع التخزين المؤقت لاستجابات كلمات المرور عبر `nocache_headers()`.
- منع تخزين كلمات المرور كنص صريح في قاعدة البيانات أو User Meta أو التخزين المحلي (LocalStorage/SessionStorage).
- منع تسريب كلمات المرور في سجلات النظام (Logs)، وتسجيل عمليات التعيين في Audit Log بصيغة آمنة.
- منع إرسال بريد ووردبريس التلقائي أثناء عملية التعيين اليدوي لعدم الاعتماد على خادم SMTP.
- إبطال فوري لجميع جلسات WordPress السابقة للحساب المستهدف عبر `wp_destroy_all_sessions`.
- إبطال فوري لتوكنات JWT الخاصة بالتطبيق الصادرة قبل تاريخ تغيير كلمة المرور عبر `dms_jwt_not_before`.
- حذف رموز الأجهزة السابقة (Device Tokens) للحساب لضمان تسجيل خروج الجلسات غير المصرح بها.

### 🛡️ الحفاظ على استقرار النظام (Stability & Compatibility)
- الحفاظ التام على منظومة استعادة كلمة المرور التقليدية عبر البريد الإلكتروني للزبائن الذين يستخدمونها.
- عدم المساس باسم المستخدم، أو رقم الهاتف، أو البريد الإلكتروني، أو دور الحساب، أو مجموعات الأسعار، أو الفواتير، أو الطلبات السابقة.
- التوافق الكامل مع تطبيق الهاتف (Android & iOS) دون الحاجة لتحديث التطبيق من المتاجر.
